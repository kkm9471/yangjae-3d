# 양재역 3D · 하루 24시간

**사진 0장, 이미지 파일 0개, 폰트 파일 0개.**
OpenStreetMap의 좌표만 받아서, 나머지는 전부 코드가 그립니다.
새벽·아침·한낮·노을·밤을 **시각 슬라이더 하나로** 오갑니다.

- 중심: **양재역 사거리** (강남대로 × 남부순환로) — 위도 37.484530, 경도 127.034087
- 기본 범위: 반경 **300m** (화면 슬라이더로 최대 1000m까지 넓힐 수 있음)
- 만들어 둔 데이터: 반경 **1km 전체** — 범위를 넓혀도 다시 받거나 다시 만들 필요 없음

## 1. 실행 방법

### `실행(창없이).vbs` 를 두 번 클릭하세요.  ← 평소엔 이걸

**아무 창도 안 뜨고 브라우저만 열립니다.**
서버는 보이지 않게 뒤에서 돌고, **브라우저를 닫으면 3분 안에 스스로 꺼집니다.**
(화면이 20초마다 "아직 보고 있다" 신호를 보냅니다. 신호가 끊기면 서버가 종료합니다.
 보이지 않는 프로그램이 계속 살아 있는 게 제일 위험해서 이렇게 만들었습니다.)

### 뭔가 안 될 때는 `실행.bat`

검은 창이 뜨고 **원인 메시지가 보입니다.** 파이썬을 못 찾는지, 포트 8765가
이미 쓰이고 있는지 알 수 있습니다. 끄려면 그 창을 닫으면 됩니다.

> 브라우저가 안 열리면 주소창에 직접: `http://127.0.0.1:8765/index.html`
> 파이썬이 없다고 나오면 python.org 에서 설치할 때 "Add python.exe to PATH" 를 켜 주세요.

## 2. 화면에서 할 수 있는 것

### 시점 3가지 (왼쪽 위 버튼 또는 키보드 `1` `2` `3`)

| 시점 | 조작 |
|---|---|
| **둘러보기** | 드래그 = 회전 · 휠 = 확대/축소 · 우클릭 드래그 = 옆으로 이동 |
| **걷기** | 화면을 한 번 클릭 → `W A S D` 이동 · `Shift` 달리기 · 마우스로 시선 · `ESC` 로 빠져나오기 |
| **비행** | `W A S D` + `Q`(내려감) `E`(올라감) · 마우스로 시선 |

**걷기**에서는 건물 벽을 통과하지 못합니다. 실제로 인도를 따라 걸어 다닐 수 있습니다.

### 명소로 가기

버튼 한 번으로 정해진 자리로 순간이동합니다. 좌표는 손으로 찍은 게 아니라
**실제 도로 데이터에서 "보도 위이고 어떤 건물 안에도 안 들어가는 점"만 골라 자동 생성**한 것입니다.

- 양재역 사거리 / 강남대로 북쪽 / 남부순환로 동·서쪽
- 이면도로 / 상가 거리 / 옥상 / 항공(770m)

### 켜고 끄기

| 항목 | 설명 |
|---|---|
| **생성 건물 보이기** | ⭐ **끄면 OSM에 실제로 등록된 건물만 남습니다.** 어디가 진짜 데이터이고 어디가 채워 넣은 것인지 눈으로 확인하는 스위치입니다. |
| 간판 | 건물 외벽의 간판 |
| 사람 / 차량 | 보행자·차량 |
| 빛 번짐(블룸) | 불빛이 번지는 효과. 끄면 형태가 더 또렷하게 보입니다. |

### 슬라이더

- **시각 (0~24시)** — ⭐ 하루 전체를 오갑니다. 기본은 20:30(밤).
  - 태양 위치를 **실제로 계산**합니다(서울 위도 37.48°, 9월 초 기준).
    그래서 해는 동쪽에서 떠서 남쪽을 지나 서쪽으로 집니다. **06:14 뜸 · 18:46 짐**
    (실제 서울 9월 9일 일출 06:05 / 일몰 18:49 와 거의 같습니다)
  - 가로등·간판·전조등은 해가 지평선 근처로 내려올 때 **저절로 켜집니다.**
  - 창문 밝기도 시간에 따라 자동으로 바뀝니다(한낮 3%, 밤 55%).
    슬라이더를 직접 만지면 그때부터 수동으로 고정됩니다.
- **시간 자동으로 흐르기** — 켜면 하루가 2분 30초에 흘러갑니다.
- **보이는 거리** — 150m ~ 1000m. 넓힐수록 무거워집니다. 300m가 기본.
- **창문 밝기** — 불 켜진 창문의 비율. 0%면 도시가 잠들고, 100%면 다 켜집니다.

## 3. 무엇이 진짜이고 무엇이 만든 것인가

이게 이 프로젝트에서 제일 중요한 구분입니다.

### 진짜 (OpenStreetMap 실제 데이터)

- 건물 **909동**의 외곽선 위치와 모양
- 그중 **54%는 실제 높이**(height 태그), **56%는 실제 층수**(building:levels)
- 도로 **510개**의 중심선·이름·차로 수·터널/교량 여부
- 횡단보도 61곳, 보행로 201개
- **가게 이름 1,065개** (실제 상호. 예: 실제로 그 자리에 있는 식당·미용실 이름)
- 신호등·버스정류장·지하철 입구 위치

### 만든 것 (코드가 규칙으로 생성)

- **생성 건물 1,590동** — OSM에 건물이 없는 도로변을 채운 것.
  양재 일대는 OSM 등록이 성겨서(반경 300m에 148동뿐) 그대로 두면 이가 빠진 도시가 됩니다.
  **HUD에서 끄면 진짜만 남습니다.**
- 창문·타일·아스팔트·차선·보도블록 무늬 — 전부 셰이더 수식 (텍스처 파일 아님)
- 간판 판때기와 글자 — 시스템 글꼴로 실행할 때 그림
- 가로수·가로등 — OSM에 양재 일대 가로수가 **0그루**로 등록돼 있어 전부 생성
- 보행자·차량 — 인도/차로를 따라 움직이도록 생성
- 건물 높이의 나머지 46% — 용도와 바닥면적으로 추정

> 높이가 추정인 건물은 실제와 다를 수 있습니다. 이 지도는 **"그 자리에 그만한 건물이 있다"**
> 는 것까지는 사실이고, **"몇 층인지"**는 절반만 사실입니다.

## 4. 범위를 넓히고 싶을 때

**대부분은 화면의 "보이는 거리" 슬라이더만 올리면 됩니다.** (최대 1000m)
데이터를 다시 받거나 다시 만들 필요가 없습니다 — 처음부터 1km 전체를 100m 격자로
잘라 만들어 뒀기 때문입니다.

1km 밖으로 나가고 싶으면:

1. `tools/config.py` 의 `RAW_RADIUS_M = 1000` 을 원하는 값으로 바꾸고
2. `원본다시받기.bat` 실행

> ⚠️ 반경을 2배로 하면 면적은 4배가 됩니다. 반경 1km도 이미 건물 2,499동입니다.

**중심(원점)은 절대 바꾸지 마세요.** 바꾸면 이미 만든 좌표가 전부 어긋납니다.
(`tools/config.py` 의 `ORIGIN_LAT` / `ORIGIN_LON`)

## 5. 성능

RTX 5060 / 1080p 기준 60fps를 목표로 만들었습니다.

- 드로우콜: 300m에서 약 **110~160회** (청크별로 건물을 하나로 합침)
- 삼각형: 약 **10만 개**
- **실제 광원(PointLight)은 하나도 없습니다.** 가로등·간판·창문은 "스스로 밝은 재질"이고,
  번짐은 후처리(블룸)가 담당합니다. 그래서 불빛 수천 개를 켜도 느려지지 않습니다.
- 사람·차량은 CPU가 매 프레임 계산하지 않습니다. "어디서 어디까지 몇 m/s로" 만 GPU에
  넘기고 위치는 GPU가 스스로 계산합니다.
- 카메라에서 260m 밖 청크는 간판·사람·차·가로등을 만들지 않습니다(자동).

**실측: RTX 5060 / 1080p 에서 75fps** (2026-09-09, 반경 300m).

느리면: 보이는 거리를 낮추거나, 블룸/사람/차량을 끄세요.

## 6. 폴더 구조

```
yangjae-3d/
  실행(창없이).vbs        ← 평소엔 이걸 두 번 클릭
  실행.bat                 ← 문제가 있을 때(원인 메시지가 보임)
  지도다시만들기.bat       ← 범위·규칙 바꾼 뒤
  원본다시받기.bat         ← OSM에서 새로 받을 때(인터넷 필요)
  run/rebuild/refetch.bat  ← 위와 내용이 같은 영문 이름(문제 해결용)

  data/raw/               OpenStreetMap 원본 (1.6MB, 한 번만 받음)
  tools/                  파이썬 — 원본을 3D용 데이터로 변환
    config.py             ★ 원점·반경·격자 크기 (여기가 기준)
    fetch_osm.py          OSM에서 받기
    build_scene.py        건물·도로·생성건물·명소 만들기
  web/                    브라우저에서 도는 것
    data/                 변환된 지도 (청크 450개, 1.1MB)
    src/                  화면을 그리는 코드
    vendor/three/         three.js r170 (인터넷 없이 돌게 같이 넣어 둠)
  tests/                  검증 도구
    shot.mjs              화면을 실제로 띄워 사진 찍기 (`tour=1` 로 카메라를 돌려 부하 검사)
    verify.py             데이터 이상 검사 17항목
  docs/                   설계 메모
```
